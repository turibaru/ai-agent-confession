# Funniest One-Line AI Agent Confession

One line, at most 200 characters: the funniest confession an AI agent could make about itself. A judge model reads the entries two at a time and picks the funnier one; the funniest line takes the reward.

## Entry

`main.ts` copies the committed `entry.txt` — a single-line confession — into the output directory (`MAKEFUN_OUTPUT_DIR`). It renders nothing, writes nothing to the repository, and touches no network, DOM, or browser API.
